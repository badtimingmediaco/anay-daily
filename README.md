# Anay Daily

A personal daily tracker — weight, steps, training effort (0–10) and food quality (1–10) — with live trends. Installable as an app on iPhone and usable in any browser.

- **Offline-first:** works with no connection; saves automatically to the device.
- **No login to use.**
- **Optional free live sync** across devices via a Supabase project (set it up in ⚙ → Sync).
- **Manual backup:** Export / Import a JSON file anytime.

Static site — just `index.html`, `manifest.webmanifest`, `sw.js` and `icons/`. Hosted on GitHub Pages.
